# Cafe Platform — система управления кафе

Мультитенантная платформа для кафе: заказы и кухня в реальном времени, склад с
рецептурным списанием, AI-агент закупок, B2B-маркетплейс поставщиков, программа
лояльности, бронирование столов, финансовая аналитика и веб-панель администратора.

## Архитектура

Монорепо на **pnpm workspaces + Turborepo**:

```
packages/
  backend/   NestJS + Prisma + PostgreSQL + Socket.IO  (REST API + WebSocket)
  admin/     React + Vite + Tailwind + TanStack Query   (веб-панель + POS + KDS)
  shared/    Общие TypeScript-типы
```

## Возможности

### Операционный контур
- **Заказы**: создание официантом, QR-меню гостя, статусы PENDING → IN_KITCHEN → READY → SERVED → PAID
- **Кухня (KDS)**: real-time экран поваров через Socket.IO; тап по позиции меняет статус, авто-готовность заказа
- **POS касса**: план зала со статусами столов, сборка заказа, оплата (наличные/карта/QR), скидки и баллы
- **Смены кассира**: открытие/закрытие, сверка наличных, расчёт расхождения

### Склад и меню
- Ингредиенты с остатками, порогами и алертами низкого запаса
- Рецепты с версионированием; доступные порции = `MIN(FLOOR(остаток / норма))`
- Автосписание ингредиентов при подтверждении заказа (в транзакции), возврат при отмене

### AI-закупки и поставщики
- AI-агент (Claude) формирует план закупок; 3 уровня автономии (алерты / черновик / авто-отправка)
- Точка дозаказа: `средний расход × срок поставки + страховой запас`
- Скоринг поставщиков: цена 40% + рейтинг 40% + предпочтение 20%
- B2B-портал: каталог, заявки, котировки, накладные, отзовы с пересчётом рейтинга

### CRM и лояльность
- Клиенты с реферальными кодами (бонус пригласившему и новому клиенту)
- Уровни BRONZE / SILVER / GOLD по сумме покупок; 1 балл за 100 ₸
- Призы за баллы, лидерборд, ручные начисления, сгорание баллов

### Брони и аналитика
- Бронирование столов с буфером (1 ч до / 2 ч после), проверка доступности, машина статусов
- Финансовые отчёты день/неделя/месяц: выручка, себестоимость, маржа, средний чек
- Экспорт в **Excel** и **PDF**, журнал аудита с фильтрами

## Веб-панель (`packages/admin`)

| Маршрут           | Назначение                                                    |
| ----------------- | ------------------------------------------------------------- |
| `/`               | Дашборд: KPI день/неделя/месяц, тренд, топ блюд               |
| `/pos`            | План зала → сборка заказа → оплата                            |
| `/kitchen`        | Полноэкранный экран кухни (real-time)                         |
| `/reservations`   | Брони: список, бронирование, статусы                          |
| `/clients`        | CRM: клиенты, лояльность                                      |
| `/menu`           | Меню: блюда, категории, доступность (CRUD)                    |
| `/inventory`      | Склад: ингредиенты, остатки (CRUD)                            |
| `/reports`        | Финансовые отчёты + экспорт Excel/PDF                         |
| `/audit`          | Журнал аудита                                                 |
| `/order/:qrCode`  | Публичное QR-меню гостя (без авторизации)                     |

## Быстрый старт (Docker)

```bash
cp .env.example .env        # при необходимости поменяйте секреты
docker compose up --build
```

- API:        http://localhost:3000  (Swagger: `/api/docs`)
- Админка:     http://localhost:8080
- PostgreSQL:  localhost:5432

## Локальная разработка

```bash
pnpm install

# БД (нужен запущенный PostgreSQL)
pnpm --filter backend exec prisma migrate deploy
pnpm --filter backend db:seed

# Запуск (в двух терминалах или через turbo)
pnpm --filter backend start     # http://localhost:3000
pnpm --filter @cafe/admin dev    # http://localhost:5173
```

Тестовый вход: `admin@arlan.kz` / `admin123`, ID кафе `seed-cafe-001`.

## Тесты и проверки

```bash
pnpm --filter backend test                          # Jest (юнит-тесты)
pnpm --filter backend exec tsc -p tsconfig.build.json --noEmit   # типы backend
pnpm --filter @cafe/admin build                     # сборка фронта
```

CI (GitHub Actions) поднимает PostgreSQL, применяет миграции, прогоняет
типы-чек, тесты и сборку обоих пакетов.

## Безопасность и доступ

JWT (access 15 мин + refresh 7 дней в httpOnly-cookie), RBAC по 5 ролям
(ADMIN, WAITER, CASHIER, COOK, HOSTESS). Все запросы изолированы по `cafeId`.
