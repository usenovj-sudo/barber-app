# @cafe/admin — Админ-панель

Веб-интерфейс владельца кафе. React + Vite + TypeScript + Tailwind + TanStack Query.

## Запуск

```bash
# из корня монорепо
pnpm install
pnpm --filter @cafe/admin dev      # http://localhost:5173
```

Бэкенд должен быть запущен на `http://localhost:3000` (порт настраивается через
`VITE_API_URL` в `.env`).

## Вход

Тестовые данные сидов: `admin@arlan.kz` / `admin123`, ID кафе `seed-cafe-001`.

## Страницы

| Маршрут       | Описание                                                        |
| ------------- | --------------------------------------------------------------- |
| `/`           | Дашборд: KPI за день/неделю/месяц, тренд выручки, топ блюд       |
| `/reports`    | Финансовый отчёт с переключателем периода + экспорт Excel/PDF    |
| `/inventory`  | Склад: остатки ингредиентов, подсветка низких остатков          |
| `/menu`       | Меню: блюда по категориям, себестоимость, маржа, доступные порции|
| `/audit`      | Журнал аудита: фильтры по сущности/действию, пагинация           |

## Аутентификация

JWT access-token хранится в `localStorage`, добавляется в каждый запрос через
axios-интерсептор. При `401` сессия сбрасывается и пользователь уходит на `/login`.
